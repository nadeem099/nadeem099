<details>
<summary><b>Notes on how I approach RAG</b></summary>

<br/>

- **Retrieval beats prompting.** Most "hallucination" bugs are recall bugs. Fix the index first.
- **Hybrid by default** — BM25 + dense, then a cross-encoder rerank on the top ~50.
- **Chunking is a product decision**, not a constant. Structure-aware > fixed 512.
- **Evaluate before you tune.** No golden set means no signal, just vibes.
- **Cite or abstain.** If the answer isn't in the retrieved context, the model says so.

</details>
